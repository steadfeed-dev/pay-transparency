# Steadfeed — public site (getsteadfeed.com)

Static website for Steadfeed, a small software studio making practical web and data tools sold pay-per-use on the [Apify Store](https://apify.com/steadfeed).

## Pages
- `/` (`index.html`): Steadfeed home, grouped by audience. An "I'm…" picker in the hero and a sticky audience bar jump to four groups: HR & hiring (`#hr`: free checker, Pay Transparency Compliance Monitor, extractor, ATS monitor), Etsy & online sellers (`#sellers`: Etsy Listing Health Checker, coming soon, no link or price), Website owners & marketers (`#web`), and Developers & AI assistants (`#developers`: both MCP servers, Screenshot & PDF API, API note). Older anchors still land: `#monitoring` (Page Change Monitor card) and `#ai-tools` (MCP servers). Generated by `ptcm-site-build/build_home.py`.
- `/pay-transparency/`: the Pay Transparency Compliance Monitor landing page (moved intact from `/`).
- `/pay-transparency/checker/`: free Pay Transparency Checker. A visitor pastes one job posting and gets which US posting laws apply, the pay range found and plain-English fixes. Runs entirely client-side (ES modules, no network requests); the posting text never leaves the browser. Rule table and pay-range parser are copied from the Pay Transparency Compliance Monitor actor by `ptcm-site-build/sync_checker_lib.py` (into `checker/lib/`); checker-only rule updates live at the top of `checker/engine.js`. Page HTML is generated by `ptcm-site-build/build_checker.py`; sample-posting tests are in `ptcm-site-build/checker-tests/` (`node run.mjs`).
- `/privacy.html`, `404.html`, `robots.txt`, `sitemap.xml`.

Old single-page links such as `getsteadfeed.com/#pricing` or `/#faq` are forwarded to the same section on `/pay-transparency/` by a small inline script in the home page `<head>` (query strings are kept).

## Notes
- No build step and no cookies. Cloudflare Web Analytics (cookie-free, aggregate visit counts) is the only third-party script. `assets/site.js` toggles the mobile menu and highlights the current group in the home audience bar (no network requests). Font is self-hosted (Inter variable, SIL Open Font License). Icons are inline SVG.
- PTCM example reports use fictional postings from an invented "Example Co." and are labeled as such. Findings are potential issues for human review, not legal advice.
- Product names, descriptions and prices on the home page come from the public Apify Store listings. Update them when a Store listing changes.
- GitHub Pages is served from the `main` branch, site root. Custom domain: `CNAME` contains `getsteadfeed.com`.
- Links to the Apify Store include UTM parameters (`utm_source=steadfeed-site`; campaign `steadfeed-home` on the home page, `ptcm-landing` on the PTCM page) so conversions can be read from Store traffic, not from trackers on this site.
