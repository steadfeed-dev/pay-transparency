# Pay Transparency Compliance Monitor — public site

Static landing page for [Pay Transparency Compliance Monitor](https://apify.com/steadfeed/pay-transparency-compliance-monitor), a Steadfeed product from OSW LLC (Our Spark Works).

- No build step, no JavaScript, no cookies, no analytics, no third-party requests. Fonts are self-hosted (Fraunces and Source Sans 3, SIL Open Font License).
- The “Live sample” section is from an actual Actor run (build 0.1.9, run `jh1xTIXx2SaHObimw`, 10 November 2026, 8:31 PM PT). Source files are in `assets/sample/`. Findings, when present, are potential issues for human review.
- GitHub Pages is served from the `main` branch, site root. Live URL: `https://steadfeed-dev.github.io/pay-transparency/`.
- Custom domain later: add a `CNAME` file containing the domain (do not add it until the domain is purchased and DNS is ready), set the custom domain in the repository’s Pages settings, and enable HTTPS. There is no `CNAME` file in this repository yet.

CTA links to the Apify Store include UTM parameters (`utm_source=steadfeed-site`) so conversions can be read from Store traffic, not from trackers on this site.
